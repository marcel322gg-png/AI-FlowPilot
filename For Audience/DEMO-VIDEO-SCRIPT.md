# FlowPilot promo — 60-second production script

**Format:** 1920×1080, 16:9, 30 fps, H.264/AAC, target under 50 MB. At least 75% must be genuine moving footage from the running application. No AI-generated UI, customer data, or synthetic analytics overlays.

## Timeline and narration

| Time | Picture / interaction | Voiceover / on-screen copy |
|---|---|---|
| 0–5s | Indigo FlowPilot wordmark reveal over a clean light canvas; quick cut into the live dashboard. | “Meet FlowPilot: a local-first workspace for turning inquiries into clear next steps.” |
| 5–13s | Live Dashboard. Cursor selects 7-day, then 30-day range; gently push into the incoming-leads chart and KPI cards. | “See database-backed lead volume, priorities, sources, and qualification at a glance.” |
| 13–23s | Live Inbox. Type a search, open filters, set a status, change sorting; open a result. | “Find the right inquiry quickly with search, filters, sorting, and direct links.” |
| 23–34s | Live lead details. Scroll through original inquiry, score, intent, sentiment, summary, suggested reply, and activity. | “Review the original message alongside local AI classification and its activity history.” |
| 34–43s | Live New Inquiry form. Fill with fictional `.invalid` contact details and submit; show the resulting lead. | “Capture a fictional inquiry and let the local workflow prepare it for manager review.” |
| 43–51s | Live n8n editor. Show both actual FlowPilot workflows in the workflow list/canvas. | “n8n coordinates qualification and records workflow failures.” |
| 51–57s | Live Integrations screen, then return to Dashboard. | “When Ollama is offline, deterministic Demo Mode keeps intake available.” |
| 57–60s | Wordmark and local-first closing card. | “FlowPilot. Clearer follow-up, on your own machine.” |

## Capture and edit notes

- Record the app at a consistent 1920×1080 viewport, 30 fps. Keep browser chrome and developer tools outside the capture.
- Use real cursor movements and clicks; wait for data and transitions before each take. Use a new test inquiry only if it can be removed through the UI after recording.
- Keep product footage above 45 seconds of the 60-second cut. Titles and transitions together should remain under 15 seconds.
- Apply gentle push-ins/crops, short cross-dissolves, restrained indigo feature labels, and subtle cursor emphasis. Never obscure values or imply unverified results.
- Use licensed/original music only; mix below narration. Burn no credentials, emails, or private account data into frames.
- Export English narration with English and Ukrainian subtitle tracks. Validate the output duration, frame size, frame rate, codecs, and file size before delivery.
