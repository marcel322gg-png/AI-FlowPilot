# FlowPilot · 45-second demo walkthrough

**0–7 sec — Dashboard**  
Show the local lead dashboard and point out the database-derived totals, priority count, category distribution, and recent activity.

**7–15 sec — Inquiry intake**  
Open the demo form and submit a synthetic pricing inquiry. Mention that form submission returns quickly while qualification runs asynchronously.

**15–25 sec — Qualification**  
Open the resulting lead. Show category, priority, score, sentiment, summary, and the visible AI or Demo Mode label.

**25–34 sec — Manager review**  
Edit the suggested reply, save it, copy it, and change the lead status. Explain that sending remains a manual manager action.

**34–41 sec — Repeat inquiry**  
Submit another synthetic inquiry from the same email and show that the existing lead is updated and the repeat is tracked in its activity history.

**41–45 sec — Integrations**  
Show API, PostgreSQL, n8n, and Ollama availability on the local integrations page.

Capture this walkthrough only from a running instance. Do not imply external clients or real customer data.
