PROJECT TITLE
FlowPilot — Local-first lead qualification

SHORT DESCRIPTION
A local-first CRM that turns incoming inquiries into organized, AI-assisted follow-up for small teams.

PROJECT OVERVIEW
FlowPilot captures inquiries in PostgreSQL, detects repeat submissions, and prepares a qualification summary using a local Ollama model. If Ollama is unavailable, deterministic Demo Mode keeps the workflow usable. Managers can review leads in a searchable, filterable inbox, inspect the original inquiry and activity history, update status, edit a suggested reply, and remove a lead with its related activity.

The dashboard presents database-backed lead totals and status, category, priority, source, and score distributions, with 7-, 30-, and 90-day trend ranges. n8n provides qualification and workflow error-handling automation. Suggested replies remain drafts and are never sent automatically.

TECHNOLOGY
React, TypeScript, Vite, Node.js, PostgreSQL, n8n, Ollama, Docker Compose.

PROJECT STATUS
Independent portfolio project with fictional demonstration data. Local automated tests, production builds, and service checks have passed. This is not a client engagement or commercial deployment, and no business outcomes are claimed.

DEVELOPMENT APPROACH
An AI-assisted, iterative build focused on connecting a usable CRM interface with persistent storage and local automation. Features were checked through automated tests and the running local application.
